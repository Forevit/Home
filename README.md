## ✨ Visual

- Design **glassmorphism** com fundo animado (orbs gradientes)
- Cards translúcidos com backdrop-filter blur
- Animações de scroll suaves (fade-up com IntersectionObserver)
- Navegação fixa com blur
- Totalmente responsivo (mobile-first)
- Fontes: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) + [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## 🚀 Como usar

O site é um único arquivo HTML estático — sem dependências, sem build. Para publicar no GitHub Pages:

1. Faça o fork ou clone do repositório
2. Substitua `Eduardo.jpg` pela sua foto
3. Ative o **GitHub Pages** nas configurações do repositório (Settings → Pages → Branch: `main`)
4. Acesse via `https://seuusuario.github.io/Home`

## 🛠️ Tecnologias

- HTML5 / CSS3 / JavaScript (vanilla)
- CSS Custom Properties (variáveis)
- CSS `backdrop-filter` (glassmorphism)
- `IntersectionObserver` API (animações de scroll)
- Google Fonts (sem dependências de build)
